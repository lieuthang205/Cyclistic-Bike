# Cyclistic-Bike
Phân tích hành vi: Nhấn mạnh sự khác biệt giữa hai nhóm khách: Thành viên (Member) sử dụng xe như phương tiện đi làm hàng ngày (biểu đồ đường hình chữ M), trong khi khách Vãng lai (Casual) sử dụng xe chủ yếu vào cuối tuần để giải trí.

Kiến nghị chiến lược: Đề xuất với doanh nghiệp: Xây dựng các chiến dịch ưu đãi tại các trạm xe gần khu văn phòng vào giờ cao điểm để chuyển đổi khách vãng lai thành thành viên.
